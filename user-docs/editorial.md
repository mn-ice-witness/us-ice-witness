# Editorial Rules

## What We Document

- ICE/CBP civil rights incidents in your state
- Must have at least one credible news source
- Every claim must link to a source

## Language

Use neutral, documentary language:

| Don't Say | Say Instead |
|-----------|-------------|
| raid | search |
| victim | affected individual |
| kidnapped | detained |
| horrific, shocking | *(describe facts)* |

## Trustworthiness

| Rating | When to Use |
|--------|-------------|
| **high** | 3+ sources, or video evidence, or investigative report |
| **medium** | 2 sources, or single major outlet |
| **low** | Single small outlet, social media only |
| **no-news-media** | Rumors, anonymous tips |

## Source Format

```
1. Outlet Name (Mon DD, YYYY): [Article Title](URL)
```

Every source must have a working link.
