## Quick Start

1. [Set up your repo](setup.md)
2. [Add incidents](incidents.md) (use Claude Code)
3. [Add media](media.md)
4. Push to `main` → your site updates automatically

## Recommended: Use Claude Code

Open Claude Code (with Opus 4.5) in your state repo folder. Just tell it what you want:

> "Add this incident: [paste news URL]"

Claude handles the rest.
