# ICE Witness Documentation

Documentation for state maintainers of ICE Witness repositories.

## Overview

ICE Witness documents ICE enforcement actions across U.S. states. Each state has its own repository containing incident reports and media.

---

## What You Manage vs. What's Generated

### Files You Create

| File | Location | Purpose |
|------|----------|---------|
| Incident files | `docs/incidents/YYYY-MM/DD/YYYY-MM-DD-slug.md` | Source of truth for incidents |
| Raw media | `raw_media/` | Unprocessed videos/images |
| State config | `ice-witness.config` | State code, name, contact |
| About page | `docs/about.md` | Your state's about page |

### Files the System Generates

| File | Location | Generated By |
|------|----------|--------------|
| incidents-summary.json | `docs/data/` | Pre-commit hook |
| Processed media | `docs/media/` | `process_media.py` |
| OG images | `docs/media/` | `process_media.py` |

The website reads from generated files. You only edit source files.
