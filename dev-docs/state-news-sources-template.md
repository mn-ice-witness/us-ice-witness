# State News Sources Template

This document provides guidance for identifying and documenting news sources for each state repository.

## How to Use This Template

Each state repo should have a `NEWS-SOURCES.md` file in its root directory documenting the primary news sources for that state.

## Categories of Sources

### Tier 1: Major Daily Newspapers
- Largest circulation newspapers in the state
- Usually cover the entire state or major metro areas
- Examples: Star Tribune (MN), Seattle Times (WA), Portland Press Herald (ME)

### Tier 2: Television News Stations
- Network affiliates (ABC, CBS, NBC, FOX)
- Cover breaking news and local events
- Often have video footage of incidents

### Tier 3: Public Media
- State public radio/TV (MPR, KUOW, Maine Public)
- Often do deeper investigative reporting
- Good for context and analysis

### Tier 4: Regional/Local Papers
- Cover specific cities or regions
- May have unique local coverage
- Important for incidents outside major metros

### Tier 5: Independent/Online News
- Non-profit news organizations
- Investigative outlets
- Community-specific publications

### Tier 6: Immigration-Specific Sources
- Local immigrant advocacy organizations
- Immigration legal aid groups
- Community hotlines and watch programs

## What to Document

For each source, include:
- **Name**: Official outlet name
- **Type**: Newspaper, TV, Radio, Online, etc.
- **Coverage Area**: State, metro area, region
- **URL**: Main website
- **Immigration Coverage**: Notes on how they cover immigration issues
- **Reliability**: How consistent/thorough their coverage is

## Searching for Incidents

When researching incidents for a state, search:
1. State name + "ICE" + "arrest" + year
2. State name + "immigration enforcement" + year
3. Major city + "ICE raid" + year
4. State name + "deportation" + year
5. Check DHS press releases filtered by state
6. Check local advocacy organization social media
